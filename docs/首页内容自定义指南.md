# 首页内容自定义指南

## 适用场景

本指南面向 **Sub2API 管理员**，用于在「系统设置 → 站点设置 → 首页内容」中自定义平台首页的展示内容。

设置首页内容后，默认首页（含站点名称、副标题、功能特性卡片、支持的服务商标签等）将被完全替换。自定义内容支持 **HTML 模式** 和 **iframe 模式**，可满足从简单公告到复杂产品介绍等多种场景。

## 内容格式与渲染规则

首页内容字段支持 **两种渲染模式**，系统根据输入内容自动判断：

### 模式一：iframe 模式（URL）

- **触发条件**：输入内容以 `http://` 或 `https://` 开头（忽略前后空白）
- **渲染方式**：使用 `<iframe src="..." class="h-screen w-full" allowfullscreen></iframe>` 全屏嵌入
- **适用场景**：将任意外部网页作为首页，如外部文档站、Notion 页面、自建 Landing Page 等
- **注意事项**：
  - 目标网站必须允许被 iframe 嵌入（未被 `X-Frame-Options` 或 `Content-Security-Policy: frame-ancestors` 限制）
  - 如果页面显示空白或报错，请确认目标网站允许嵌入，或改用 HTML 模式

### 模式二：HTML 模式

- **触发条件**：输入内容不以 `http://` 或 `https://` 开头
- **渲染方式**：使用 Vue 的 `v-html` 指令直接渲染 HTML 字符串
- **适用场景**：编写自定义 HTML 页面，如公告、产品介绍、服务说明等
- **安全说明**：该字段仅管理员可编辑，代码注释标明 XSS 风险可接受（`SECURITY: homeContent is admin-only setting, XSS risk is acceptable`），因此 **不对内容进行 DOMPurify 过滤**

### 渲染支持能力

| 能力 | 是否支持 | 说明 |
|------|----------|------|
| 基础 HTML 标签（h1-h6, p, div, span, ul, ol, li, a, img, table 等） | ✅ 支持 | 通过 `v-html` 直接渲染 |
| 内联 CSS 样式（style 属性） | ✅ 支持 | `v-html` 会保留 style 属性 |
| 自定义 CSS（style 标签或 style 属性中的 @keyframes、transition 等） | ✅ 支持 | 可定义自定义动画和过渡效果 |
| 图片（img 标签、base64 Data URL） | ✅ 支持 | 可引用外部图片 URL 或 base64 嵌入 |
| TailwindCSS 原子类 | ⚠️ 有条件支持 | 项目已集成 TailwindCSS，但 `tailwind.config.js` 的 `content` 只扫描 `./index.html` 和 `./src/**/*.{vue,js,ts,jsx,tsx}`，**没有 safelist**。因此只有项目源码中已经出现过的类才会出现在构建后的 CSS 中。管理员在运行时输入的 Tailwind 类，如果源码中从未使用过，**不会生效**。 |
| 外部 JavaScript（script 标签） | ⚠️ 技术上可渲染，不建议 | v-html 不会执行 `<script>` 标签（Vue 限制） |
| Markdown 语法 | ❌ 不支持 | 界面提示"支持 Markdown & HTML"，但 **代码实现中没有任何 Markdown 解析库（如 marked）**。输入的 Markdown 会作为纯文本原样输出 |
| DOMPurify 安全过滤 | ❌ 不启用 | 内容不做 sanitization，由管理员对输入内容负责 |

### 容器结构

自定义内容会被包裹在一个 `class="min-h-screen"` 的 div 容器中。HTML 模式下的内容直接渲染在该 div 内，iframe 模式下 div 内仅包含一个全屏 iframe。

## 管理员填写建议

### 基础原则

1. **直接写 HTML**：不要写 Markdown 语法（如 `# 标题`、`**加粗**`、`- 列表`），这些不会被解析。
2. **优先使用内联 style**：由于 TailwindCSS 的 content 扫描机制，运行时新增的类名可能未被打包到构建产物中。为保证渲染稳定，**建议以 inline `style` 属性为主**，TailwindCSS 类仅作辅助。
3. **关于 TailwindCSS 类的使用**：可以使用已存在于构建产物中的类（即项目源码中已经出现过的类），但 **不保证任意 Tailwind 类都生效**。如果某个 Tailwind 类没有生效，请改用等价的 inline style。
4. **注意暗色模式**：如果使用 TailwindCSS 类，使用 `dark:` 前缀变体适配暗色模式。使用 inline style 时需自行处理暗色模式兼容（见下方 Q4）。
5. **图片引用**：使用完整的 HTTPS URL 或 base64 Data URL，不要使用相对路径。
6. **闭合标签**：确保 HTML 标签正确闭合，否则可能导致渲染异常。

### 不建议的做法

- ❌ 不要使用 `<script>` 标签尝试执行 JS 代码（v-html 不会执行）
- ❌ 不要写 Markdown 语法（不会被解析）
- ❌ 不要输入不完整的 HTML（如只写 `<div>` 不闭合）
- ❌ 不要依赖尚未在源码中出现的 TailwindCSS 类名
- ⚠️ iframe 模式中避免使用禁止嵌入的站点（如大多数搜索引擎、GitHub 等）

---

## 安全与兼容性注意事项

1. **XSS 风险**：首页内容不做 sanitization 过滤，管理员请避免粘贴不可信来源的 HTML。
2. **iframe 安全**：iframe 模式受浏览器同源策略限制，被嵌入页面中的 JS 无法与父页面通信（除非双方均配置了 `postMessage`）。
3. **暗色模式适配**：使用 TailwindCSS `dark:` 变体或自定义 CSS `@media (prefers-color-scheme: dark)` 确保暗色模式下文字可读。如果内容仅使用浅色配色，暗色模式下可能看不清。
4. **移动端适配**：使用内联 style 中的 CSS 媒体查询（`@media`）或 TailwindCSS 响应式前缀确保内容在小屏幕上正常显示。
5. **页面性能**：避免内嵌超大 base64 图片或大量外部资源引用。
6. **浏览器兼容**：iframe 的 `allowfullscreen` 属性在现代浏览器中需要添加厂商前缀才能正常工作，但一般情况下浏览器已自动处理。

## 进阶：复刻默认首页视觉

### 能否通过首页内容实现与默认首页一模一样的效果？

**可以高度近似，但有明确限制。**

默认首页由 Vue 组件（`HomeView.vue`）渲染，包含以下在「首页内容」HTML 模式中 **无法直接复制** 的部分：

| 默认首页能力 | 首页内容能否复现 | 说明 |
|--------------|------------------|------|
| 背景渐变 + 装饰性模糊圆 | ✅ 可以 | 使用相同的 TailwindCSS 类（这些类已在 `HomeView.vue` 源码中，存在于构建产物中） |
| 站点名称 / 副标题 | ✅ 可以 | 需硬编码文本，无法自动读取设置值 |
| 功能特性卡片（3 张） | ✅ 可以 | HTML 结构可直接复制，图标用 SVG 替代 Icon 组件 |
| 支持的服务商标签 | ✅ 可以 | HTML 结构可直接复制 |
| Logo 图片 | ✅ 可以 | 手动填入 `<img>` 标签 |
| Terminal 动画窗口 | ✅ 可以 | Terminal 样式为纯 CSS，需在 `<style>` 标签中手动定义 |
| Vue 组件（LocaleSwitcher、Icon） | ❌ 不能 | 这些是 Vue 组件，v-html 无法渲染 |
| 主题切换按钮 | ❌ 不能 | 依赖 Vue 的 `toggleTheme` 方法和 `isDark` 响应式状态 |
| 登录状态判断 | ❌ 不能 | 无法读取 `authStore.isAuthenticated`，只能写死按钮 |
| 文档链接 | ⚠️ 可硬编码 | 无法自动读取 `doc_url` 设置值，需手动填入 URL |
| 登录/Dashboard 路由跳转 | ✅ 可以 | 使用 `<a href="/login">` 替代 `<router-link>` |

**结论：** 可以在视觉上做到 90%+ 相似（布局、配色、卡片、Terminal 动画一致），但无法完全复制交互能力（主题切换、语言切换、动态登录状态）。

## 常见问题

### Q1：为什么我写的 Markdown 没有被解析？

当前实现中，首页内容字段 **不支持 Markdown 解析**。虽然管理后台界面提示"支持 Markdown & HTML"，但代码实现（`HomeView.vue`）使用的是 `v-html` 指令直接渲染 HTML，没有引入任何 Markdown 解析库（如 marked）。请将 Markdown 转换为等价的 HTML 后再填入。

### Q2：为什么 iframe 模式页面显示空白？

目标网站可能设置了 `X-Frame-Options` 或 `Content-Security-Policy: frame-ancestors` 安全策略，禁止被 iframe 嵌入。你可以：

1. 确认目标网站是否允许嵌入（查看响应头中是否有 `X-Frame-Options: SAMEORIGIN` 或 `DENY`）
2. 改用 HTML 模式自行构建页面内容

### Q3：内容中输入的 `<script>` 标签为什么没有执行？

Vue 的 `v-html` 指令出于安全考虑，**不会执行** `<script>` 标签中的 JavaScript 代码。如果你需要动态交互，请改用 iframe 模式嵌入一个包含完整 JS 的页面。

### Q4：暗色模式下文字看不清怎么办？

由于首页内容使用内联 style 编写，TailwindCSS 的 `dark:` 变体无法直接作用于自定义 style 属性。解决方法：

**方法一**：在内容顶部使用 `<style>` 标签配合 `@media (prefers-color-scheme: dark)` 定义暗色模式样式：

```html
<style>
  @media (prefers-color-scheme: dark) {
    .my-container { color: #e2e8f0 !important; background: #0f172a !important; }
  }
</style>
<div class="my-container" style="color:#111827;background:#f9fafb;">...</div>
```

**方法二**：如果内容中使用了 TailwindCSS 类（仅限源码中已存在的类），可以直接使用 `dark:` 变体，如 `text-gray-900 dark:text-white`。

如果未做暗色适配，默认的浅色配色在暗色模式下可能几乎不可见。

### Q5：首页内容可以为空吗？清空后会怎样？

可以。清空 `home_content` 字段后，首页将恢复为默认首页（站点名称、副标题、功能特性卡片、支持的服务商标签等）。

### Q6：可以上传图片到首页吗？

可以。有两种方式：

1. **引用外部图片 URL**：使用 `<img src="https://example.com/image.png" alt="描述">`。
2. **Base64 嵌入**：将图片转为 base64 Data URL 后直接嵌入，如 `<img src="data:image/png;base64,iVBORw0KGgo...">`。但注意 base64 会大幅增加内容体积，建议用于小图标。

当前没有图片上传功能（管理后台首页内容输入框为纯 textarea，不支持图片上传）。

### Q7：是否支持 CSS 动画或过渡效果？

支持。可以在 `<style>` 标签中定义 `@keyframes` 动画和 `transition` 过渡效果，或在 `style` 属性中使用 `transition` 等 CSS 属性。例如示例中的 `animation: pulse 2s ...` 和按钮上的 `transition: background 0.2s`。

### Q8：HTML 内容有没有长度限制？

后端使用 `string` 类型存储（数据库中为 text 类型），理论上没有严格的长度限制。但过长的 HTML 内容可能影响页面加载性能，建议保持在合理范围内（一般不超过 50KB）。
